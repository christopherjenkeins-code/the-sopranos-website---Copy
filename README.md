Welcome to the repository for **The Sopranos Restaurant & Lounge** web platform. This modern multi-page website is designed to showcase the venue's fine dining, craft cocktails, VIP nightlife events, operational details, and interactive table reservation system.

---

## 📌 Project Overview

Located in Northern Roodepoort, Gauteng, South Africa, **The Sopranos Restaurant & Lounge** offers a premium culinary and nightlife experience. The web application features a fully responsive design built to provide seamless navigation for guests browsing menus or making online bookings.

### Key Pages & Features
* 🏠 **Home (`index.html`):** Dynamic hero section, current promotions, featured specials, and rapid site navigation.
* 📖 **About Us (`about.html`):** Background history, culinary philosophy, core values, and executive vision.
* 🍽️ **Menu (`menu.html`):** Interactive menu categories including gourmet burgers, wings, meat platters, signature cocktails, and weekly specials.
* 🍸 **Services (`services.html`):** Overview of fine dining options, craft cocktail bar offerings, and VIP lounge event hosting.
* 📅 **Reservations (`enquiry.html`):** Booking request form for individual dining tables, private parties, and VIP booth access.
* 📞 **Contact Us (`contact.html`):** Business opening hours, physical address, direct contact forms, and location maps.

---

## 🛠️ Built With

* **HTML5:** Semantic element architecture for accessibility and SEO optimization.
* **CSS3:** Custom responsive styling layout using Flexbox/Grid, CSS custom properties, and animations (`css/style.css`).
